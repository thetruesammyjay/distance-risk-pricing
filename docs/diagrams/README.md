# Chapter Four diagrams

The six PNG files in this directory are embedded in `docs/CHAPTER-FOUR.md`.
Each PNG has a matching `.drawio` source that can be opened and edited in
draw.io/diagrams.net:

- `chapter-four-architecture`
- `chapter-four-use-case`
- `chapter-four-activity`
- `chapter-four-sequence`
- `chapter-four-class`
- `chapter-four-er`

The source definitions and PNG exports can be regenerated with
`scripts/generate_chapter_four_diagrams.mjs` when the diagrams change.
